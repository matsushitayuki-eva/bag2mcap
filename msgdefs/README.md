# msgdefs（定義パック置き場）

`bag2mcap.exe` と同じフォルダ、またはこの `msgdefs` フォルダに `msgdefs_*.json` を置くと、
起動時に **ファイル名が最後（辞書順）のもの** が自動で選ばれます。

- 定義パックは private リポジトリのメッセージ定義を含むため **社外秘** です。社外に持ち出さないでください。
- 定義パックは Git では管理せず（`.gitignore` 済み）、GitHub Releases の添付ファイルとして社内に配布します。
- 作成手順は `docs/msgdefs_admin_guide.md` を参照してください。
