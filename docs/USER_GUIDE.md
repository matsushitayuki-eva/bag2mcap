# bag2mcap 使い方

rosbag2（`.db3`）を Lichtblick で開ける MCAP（`.mcap`）に変換するツールです。ROS 2 のインストールは不要です。

## 準備

1. 配布された `bag2mcap_<バージョン>.zip` を任意の場所に展開する
2. 定義パック `msgdefs_<pilot-auto のバージョン>.json` を `bag2mcap.exe` と同じフォルダ、または `msgdefs` フォルダに置く

## 変換手順

1. `bag2mcap.exe` をダブルクリックして起動する
   - 初回は「Windows によって PC が保護されました」と表示される場合があります。「詳細情報」→「実行」を押してください。
2. **定義パック** に、変換したい bag を記録した pilot-auto のバージョンのものが選ばれていることを確認する
3. **入力 bag** に、bag フォルダ（`metadata.yaml` と `.db3` が入ったフォルダ）をドラッグ&ドロップする（複数可）
4. 必要なら **出力先** を指定する（既定は入力フォルダと同じ場所）
5. **変換開始** を押す
6. 完了したら **出力先を開く** を押し、`<bag フォルダ名>.mcap` を Lichtblick で開く

## 結果の見方

- 出力先に `<名前>_bag2mcap_log.txt` が保存されます。トピックごとの件数や警告が記録されています。
- **「定義が見つからない型」** が表示された場合、そのトピックは Lichtblick で中身を表示できません。
  定義パックのバージョンが bag と合っているか確認し、合っている場合は管理者に型名を連絡してください。
- **「metadata.yaml がありません」**：記録が途中で終了した bag です。フォルダ内の db3 を全て変換します。
- **「スキップしました」「ファイル末尾の破損」**：壊れた db3 があります。読めた範囲までを変換しています。

## よくある質問

| 質問 | 回答 |
|---|---|
| 元の bag は変更されますか？ | 変更されません（読み取り専用で開きます） |
| 2GB の bag でどのくらい時間がかかりますか？ | PC 性能によりますが、数十秒〜数分程度です |
| 出力ファイルが既にあると言われる | 「既存ファイルを上書き」にチェックするか、既存ファイルを移動してください |
| コマンドで一括変換したい | `bag2mcap.exe -d msgdefs\msgdefs_xxx.json <bag フォルダ> [...]`（`-h` で説明を表示） |
